Atención: esta fecha no es la de entrega. Los períodos de entrega son períodos establecidos que se encuentran publicados en el campus.

Reglas que aplica
  1. Hay que aprobar las materias troncales para presentar el plan de TF.
  2. Siempre hay que aprobar el plan de TF para poder presentar el TF.
  3. Hasta la cohorte 2020 inclusive: 3 años desde que aprueban la última materia troncal para presentar el TF.
  4. Desde la cohorte 2021: 1 año desde que aprueban la última materia troncal para presentar el plan de TF, y 3 años desde que aprueban el plan para presentar el TF.
  5. Existen prórrogas, tanto para el plan de TF como para el TF: a cada caso particular se le da una fecha límite nueva.
